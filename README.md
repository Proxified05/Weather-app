# Weather App

A mobile weather application built with React Native and Expo.

## Features

- Search weather by city
- Display current and temperature and weather conditions
- Display a 48-hour and 7-day weather forecast
- Responsive mobile UI
- Real-time weather data API integration

## Technologies Used

- React Native
- Expo
- TypeScript
- OpenMeteo API
- React Native Gifted Charts
- Expo Linear Gradient

## Installation

```bash
npm install
```

## Run Project

```bash
npx expo start
```
